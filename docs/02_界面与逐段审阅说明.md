# 2 界面与逐段审阅说明

[返回总目录](00_操作手册.md)

## 2.1 主界面分区

播放画布显示图像与 Overlay；底部控制区负责切帧、播放、倍速和缩放；进度条展示帧位置及范围条带。右侧操作区执行编辑，数据区显示当前帧、身份、连续段、人工轨迹、显示设置和历史。右上信息区汇总当前片段与对象信息。

右上信息区在单选及不超过 24 个 ID 的多选中显示身份、出现帧数、连续范围和 gap 等细节；更多 ID 同时选中时显示数量汇总及当前活动行。显示简化不减少实际选择范围，也不改变表格、条带或编辑操作的对象。

Selected boxes 表示所选自动 ID 在当前工作表中的标注行数总和，跨帧计数；它不是当前画面上的框数，也不是身份数。尚未 Finish 的 Tracking 点不计入工作表行数。统计按数据修订与所选身份缓存，切帧不会重复扫描整张表。

当前帧、已选 ID、选中表格行、操作 Range、整条轨迹和分析 Start–End 不是同一范围。执行修改前，应同时核对操作区的 ID 与 Range。Display 控制可见性，并不删除隐藏的数据。

输入框悬停显示当前内容；展开下拉列表后，悬停显示所在项的完整内容，包括较长路径。具有专门说明的字段或预设在内容后补充说明；操作解释置于相关标签或按钮上，不以统一操作说明覆盖每个下拉项。

## 2.2 Current frame

该表列出当前帧的标注。点选行与画布中的框联动；在重叠框难以直接点选时，用表格确认类别、ID、中心和尺寸。Ctrl + 单击保留多选用途；Alt + 画布单击用于 Tracking，不能当作普通多选。

**规程：** 暂停视频 → 在画布或表格选择目标 → 核对 ID/类别 → 检查对应位置 → 转到需要的操作面板。多个框重叠时，不仅依赖框颜色判断身份。

## 2.3 IDs 与 Selected ID

各表使用 Shift 连续范围选择、Ctrl 增减单项和 Ctrl + A 全选。IDs 页的 Ctrl + A 仅选择当前获得焦点的类别表，不纳入其他类别表；启用筛选时不自动纳入被隐藏的身份。Edit 公共区域的 All IDs 明确选择全部身份，不能以输入框显示宽度或文字截断限制实际编辑对象。选择多个项目时保留当前滚动位置；单项定位按当前排序后的行位置居中。当前帧高亮的实际数据行同时作为表格选择和 Shift 选择的起点。

使用 Ctrl 或 Shift 点击以增加选择时，按本次点击的身份定位：当前帧已包含在该 ID 范围内则保持当前帧不跳转，否则跳转至其最近出现帧，并保持其他多选项目。Ctrl 点击取消某行选择时不因该行再次定位。大量选择分批收集，状态栏显示进度；完成前按 Esc 取消，保留上一次已经生效的选择，不修改标注或退出 Tracking。收集期间若数据、筛选或排序改变，取消过期任务，避免按旧显示行号选错身份。

IDs 类别分组及人工类别选项由 INI 的 classes、id_groups 分组定义；通用配置操作参见 [设置与性能](14_设置与性能说明.md)。

IDs 用于查看当前数据中各身份的概况；`x`、`y` 两列位于 `frame` 左侧。Selected ID 聚焦选定身份及其连续出现段，帮助定位每段首尾和 gap。实际缺失帧会把连续段分开；同一个 ID 数值不保证整段都正确对应同一个真实目标。

Current frame、Selected ID 等逐行标注表不显示重复的视频名称或路径列。视频关联属于项目级信息；选择标注来源时仍可在 File 页面核对已打开文件。

IDs 表的 x、y 列分别显示该身份标注中心在源图像中的像素坐标范围，格式为“最小值, 最大值”。例如 x 为 `120, 450`，表示已显示记录的中心横坐标介于 120 与 450 像素之间，不包含框宽度。无效或非有限坐标不参与统计；启用筛选时按筛选后的记录计算。

| 操作 | 用途 |
| --- | --- |
| 选择 ID | 显示并审阅该身份的行与范围 |
| 段首/段尾 | 快速查看缺失前后的两个端点 |
| 前/后一个连续段 | 检查重现、断轨或身份变化 |
| 下一个 gap | 找到需要插值或重新追踪的区间 |
| 画布与表格联动 | 确认当前看到的是哪个来源和身份 |

**例：静止蜜蜂暂时漏检。** 从 Selected ID 定位消失段的末帧，记录画面位置；向后切帧检查同位置是否以新 ID 出现。必要时在 Edit → Box 使用 Over time 空间框选找到这一位置出现过的身份，再用 Edit → ID 合并。

## 2.4 Manual traj 与 Binding 表

人工轨迹使用轨迹名和人工采样点；自动标注使用数值 ID。二者经 Match 对齐后才处于可比较的帧坐标上。

Manual traj 中的出现范围可能包含低帧率采样造成的 resolution gap；实际人工采样缺失形成的 GAP 与之不同。Binding 表将身份关系按段组织。选择 Binding 行时，作用范围以该行实际帧集合为准；多选使用并集，不扩大成整条身份的所有帧。

通过表格行、时间轴条带和画布诊断层交叉核对：某个自动 ID 数值出现在 Binding 行中，不意味着其全部时间范围都已被绑定。完整流程见 [Match](07_Match操作说明.md)。

## 2.5 进度条、条带与悬停

当前进度位置用于播放/切帧。黄色身份条带表示已选身份的出现范围，缺口与表格中的连续段对应。每个身份的黄色条带使用 0.6 透明度，多选身份同时出现的部分叠加后颜色更深。

| 类型 | 启用场景 | 条带样式与用途 |
| --- | --- | --- |
| 选中 ID | 全局 | 黄色细带，表示已选身份的出现范围，缺口对应轨迹中断 |
| Change position | Box 页或连续编辑会话 | 绿色，表示本次新增／暂存的帧段 |
| Tracking | Tracking 页面 | 新增范围绿色；Delete 选择范围黑色，实际有待删标注的部分红色；原身份范围仍以黄色显示 |
| Merge ID | ID 页面 | Target 蓝色、Source 绿色，同帧重叠红色；Find 候选循环彩色条带位于底层且不透明，数字为候选 ID、使用身份颜色。两者共存时原 Merge 条带在上层、透明度 0.67，重叠红色条带最后绘制 |
| 暂存记录 | 暂存窗口开启并选中记录时 | 黑色，透明度 0.3，表示该记录的暂存范围；换选记录时更新 |
| Swap 预览 | Swap 页面 | Changed 橙色；Position 的 Uncertain 紫色，提交默认跳过不确定帧 |
| Trajectory | Trajectory 页面 | 橙色，表示当前允许编辑的轨迹范围，颜色与 Preview 对应 |
| Match 对照 | Match 页面 | 自动标注淡蓝、人工轨迹淡绿、重叠淡红；用于对照双方出现范围 |
| Binding 候选 | 选中单个人工身份或开启始终显示绑定条带时 | 循环彩色条带，数字为绑定片段序号；相邻同组不重复编号 |
| Binding 核验 | 选中单个人工身份或开启始终显示绑定条带时 | Confirmed 亮绿、Confirmed · Modified 暗绿、Stale／Conflict 红色；位于候选带上方 |
| Events | Events 页面 | 使用 Event types 为各类型设置的颜色与条带行；Band 关闭时不画条带 |
| 视频导出时间范围 | File 页面 | 红色，表示 Export Range；关闭 Export settings 后仍保留当前视频的预览范围 |
| Detection 后处理预览 | Raw／Postprocess 预览期间 | Raw 覆盖范围蓝色、后处理结果范围绿色、已人工修改帧棕红色、计算已完成部分浅绿；选中范围黄色 |

Edit → ID 的 Merge Target／Source 输入还会立即为对应框添加蓝色／绿色加粗描边，切到其他子页后隐藏。候选结果窗口按当前帧居中，用黄色序号格或空档线定位；切帧保持人工单选或多选不变。行底纹与候选条带使用循环配色，表中及条带旁的候选 ID 数字使用身份分配颜色。Use 勾选才决定哪些候选填入 Source；选中或定位不表示已执行合并。

所有文字与点标记绘制在所有条带之上；文字之间沿用对应条带的上下层关系。暂存条带只表示所选草稿范围，不会自动成为公共 Range，也不会修改数据。不同用途可能位于不同高度；结合当前页面、数字标签和上表判断。

### 2.5.1 自由定位与标记点选

进度条区域用于自由定位：单击按横坐标定位，按住左键拖动可连续预览。从进度条区域开始拖动后，即使指针移到下方的标记区域或移出控件，仍按普通拖动处理，松开时定位最终位置。一次拖动只形成一条起点至终点的浏览记录。

进度条下方的标记区域用于点选可见条带与标记，不作为自由拖动区。点选覆盖黄色身份范围、Merge ID、Match、Binding／Review、Tracking 新增及删除预览、Trajectory 编辑区间和事件区间。Camera Anchor 的“+”、Capture 箭头及分析起止符号可直接点选，定位到其标记帧。隐藏或已经清除的条带不参与点选。

Start、End 符号仍绘制在进度条上，但其正下方与 Capture 箭头同高的位置也接受标记点选。点击这些对应位置定位到确切的 Start 或 End 帧；命中符号的下方区域时，优先于同位置的范围条带。进度条区域仍按横坐标自由定位。

条带按所在行命中，线上下各保留约 8 个逻辑像素的容差；同时接近多行时优先最近行，同位置重叠时优先显示在最上层的条带。点击条带内部按横坐标定位，不吸附端点。为便于观察而加宽的极短条带，其定位结果仍限制在真实帧区间内。

点击条带外侧时，根据附近可选目标间距自动调整横向吸附范围：孤立端点或点标记最多 48 个逻辑像素；相邻目标较密时收缩至相邻间距的一半，最小约 12 个逻辑像素。短 gap 内选择最近边界；等距时选择更接近当前帧的边界，仍相同时选择较早帧。悬停提示显示即将定位的帧号。逻辑像素随系统显示缩放换算，不需要调整设置。

标记区域点选在按下时确定目标，松开时仍提交该目标；鼠标释放位置改变不会跳到条带外。远处空白不切帧，也不产生浏览记录；从空白按下后再移动到轨道或条带，仍不开始拖动。定位沿用现有精确切帧机制，保留播放意图和待提交编辑；Auto Tracking 因人工定位暂停。

**例：定位断轨边界。** 某 ID 在第 100–200 帧和第 220–300 帧出现。直接点击第二段内部，定位相应帧；点击两段之间较短的 gap，且附近边界处于当前吸附范围内时，定位距离点击处最近的第 200 或 220 帧。需要查看 gap 中间的未标注帧时，在进度条区域点击或输入帧号。

### 2.5.2 画面轨迹悬停与点选

轨迹点选开启时，指针附近的可选点显示约 10 px 圆环及 `class ID (frame)`。圆环使用 ID 颜色，文字使用该处实际 trail 颜色，进度条同步标示对应帧；点击仅在该悬停点属于可见连续轨迹时定位到对应帧。

未显示的轨迹点仍可通过悬停辨认，但不能点击跳转。关闭对应 trail、被显示范围或长度过滤的点，以及没有可显示相邻线段的孤立点，均只提供悬停反馈。恢复对应线段显示后方可点选；需要定位隐藏点时可使用进度条或输入其帧号。

按住 Ctrl 可临时暂停画面上的轨迹悬停与点选，并清除由轨迹悬停产生的圆环、文字及进度条标记。松开后继续暂停 3 秒，再恢复原有 Pick trail 设置；期间重新按下并松开 Ctrl 会重新计时。原本关闭的点选不会因此开启。此操作不改写显示设置，Ctrl + 单击多选与 Ctrl + 滚轮缩放仍按原有规则执行。

before/after picking 与 All 同时限制悬停预览和点击跳转的时间范围。点击只接受当前悬停预览对应、且属于实际可见连续 trail 的点；范围外没有悬停预览的点不能点击，某方向 trail 关闭、超出其显示长度或 Frame range 的点也不能点击。指针位置 12 个逻辑像素内存在多个候选时，优先选择帧号最接近当前帧的点，再按屏幕距离确定。点击目标与悬停预览保持一致；悬停点不可点击时，不改选附近其他点。

Pick progress bar 在进度条上标示光标处的所选轨迹点，不要求对应 trail 已显示，也不受 Trail before／Trail after 的长度及 Frame range 限制；范围遵循 picking 自身的 Before／After 或 All 设置；并列候选优先当前活动身份。

## 2.6 Box 与文字显示

| 设置 | 操作效果 |
| --- | --- |
| Box / Point | 矩形框或中心点的呈现方式；不改变存储的 W/H |
| 线宽、点径、填充、透明度 | 改变显示清晰度；过大可能遮挡目标 |
| IDs / Confidence | 显示身份或可用置信度；检测置信度不同于 Tracking 匹配 Score |
| While playing | 控制播放期间是否保留相应标签，便于平衡可读性与速度 |
| ID 字号、字重、轮廓 | 使文字适应明暗背景 |
| ID 颜色、统一颜色、避让颜色 | 区分身份或增强对比；颜色不是身份记录本身 |

Tracking 当前帧的待提交框带双对角线 `⊠`，用于区别于普通已提交框并显示中心。不能依据它在画面上已出现，就认定已完成 Finish 或磁盘保存。

## 2.7 HUD 显示

HUD 用于在画面上层显示信息，Frame、Scale、Counts、Events、Camera 分别控制帧号、比例尺、类别数量、事件文字、相机关键帧与运动提示。每种类型独占一行，可分别启用、设置位置、点击 Font 选择文字颜色、填写 Size 字号、点击 Outline 选择描边颜色及填写 Outline 厚度；厚度 0 关闭描边。HUD 与目标 ID 字体独立。

位置输入格式为 `水平, 垂直, 优先级`，例如 `L, B, 2`。水平使用 L（左）、C（中）、R（右）；垂直使用 T（上）、M（中）、B（下）。同一位置的项目按优先级由小到大排列：T/B 中较小值更靠近上/下边界，M 中较小值更靠近画面中心，后续项目向上下扩展；相同优先级按设置行顺序排列。项目间预留间距；无内容的 Events 或 Camera 不占排布位置。无效位置输入在结束编辑时恢复为最后一个有效值。

默认 Frame、Scale、Counts 和相机关键帧字号为 25，Events 为 17。Camera 行的 Size 控制关键帧字号，箭头旁 Cam 采用该值的 40%，默认 10。默认 Scale 位于左下优先级 1，Frame 为左下 2，Events 为左下 3；Counts 为右下 1，Camera 为右下 2。例如将 Frame 改为 `C, T, 1`，帧号显示在顶部居中；将 Events 改为 `C, T, 2`，有效事件文字显示在帧号下方。

修改后即时预览；Save settings 的 HUD 或 All 范围保存到 settings.ini。视频导出采用相同类型、字号、颜色和描边。关闭 Events 也会隐藏 Start、End、Capture 的画面文字，不会清除实际点标记和事件记录。

## 2.8 Axis 与 Metric grid

Axis 提供显示坐标轴；原点设置可引用 Hive 或指定坐标。原点改变不等同于把 CSV 中全部对象移到新原点。

Metric grid 按 Scale 标定结果绘制物理间距网格。网格间距、外观和锚点影响呈现；Scale 类型决定像素空间中网格是否等距、是否收敛。未提供足够二维约束时，网格不能被解释为已测得完整平面透视关系。

**例：斜拍墙面。** 同为 1 cm 的网格间隔在图像上可能远处更窄、近处更宽。应先在 Scale 检查模型与约束，再用网格观察其合理性；不得为了让网格“看起来方正”而填写未知真实角度。

## 2.9 Trail before 与 Trail after

### 2.9.1 长度与对象范围

before 表示当前帧之前，after 表示之后。Frames 指显示帧数，All 使用可用的整个相应方向范围。Always trail IDs 可固定显示指定身份；Pin 将选中身份加入，Clear 移除相应固定显示项。固定显示只影响画面。

Always trail IDs 下一行的 Frame range 限制该方向允许显示的实际帧范围，空白表示不限制。可填写单帧、区间或逗号分隔的多个区间，例如 `100-300, 500-800`，包含两端。它与当前帧前后长度限制取交集，Simple trail 也受此范围限制；不同区间之间不连接轨迹。该条件同时作用于选中／固定身份、人工轨迹、Tracking 待提交轨迹、轨迹点选和视频导出，不删除任何标注。修改后离开输入框应用到显示，Save settings 保存到对应 Trail before／Trail after 分组。语法不完整时不展示整条轨迹，修正或清空后恢复。

### 2.9.2 外观参数

| 参数 | 含义 |
| --- | --- |
| Simple trail | 使用统一外观，适合检查长段轮廓 |
| 渐变起止颜色 | 分别控制靠近当前帧与远端的颜色 |
| 起止 alpha | 靠近与远端透明度，0 透明、255 不透明 |
| 起止 width | 靠近与远端的显示线宽 |
| ID colors / unique colors | 使用身份颜色或统一自定义颜色 |
| far HSV | 对远端颜色作饱和度和亮度调整 |
| Style | 实线、虚线、点线及支持的波浪等样式；不改变实际坐标点 |

渐变可帮助判断运动方向与时间先后；它不是速度数值图。看到一条连接线不能证明中间每帧都有真实检测，仍需查看实际行和来源字段。

### 2.9.3 实例：定位短暂串 ID

1. 暂停并选中目标，开启适当长度的 before/after trail。
2. 沿异常突刺悬停，读取对应帧号并点击定位。
3. 在异常帧前后逐帧检查图像，判断是位置错误还是身份交换。
4. 位置错误用 Tracking/Trajectory，身份交换用 Swap 或 Match 修复。
5. 修复后播放前后交接段，并核对实际框和轨迹来源。

## 2.10 审阅顺序与验收

优先确认视频与标注同步，再检查身份，再检查位置和几何。对每条关键轨迹依次检查起点、连续段、gap、交叉/遮挡、终点。显示隐藏、颜色一致、线条平滑都不能代替数据正确性检查。

最后确认：选中范围与执行范围一致；缺失段已说明或补齐；身份没有同帧重复；插值与人工估计仍保留来源；需核验的状态已按实际情况记录。

## 2.11 Filter：条件筛选与原表预览

### 2.11.1 入口、数据源及作用范围

Filter 位于 Edit 与 Tracking 之间。条件在此面板设置，结果仍在 Current frame、IDs、Selected ID 中查看，不另外打开遮挡表格的筛选窗口。

筛选结果完成且确实筛选掉了某张表的部分内容时，该表列标题变为绿色字 `RGB(0,175,0)`。各表各自判断：例如仅减少蜜蜂记录时，IDs 的蜜蜂表变绿，未受影响的胡蜂表保持原色。IDs 即使保留原有身份行，只要其中出现帧范围或计数减少，也属于受影响内容。Current frame 按当前帧投影判断，Selected ID 按当前活动身份判断；人工轨迹表遵循相同规则。

| 控件 | 实际行为 |
| --- | --- |
| Enable filter | 启用或关闭已应用条件的表格预览；不删除数据 |
| Annotations | 查询当前正式工作表的标注行；包括已提交的人工修正和插值 |
| Manual points | 查询导入人工轨迹的采样点；与相同数字的自动 ID 保持不同身份 |
| Both | 同时查询上述两种来源 |
| All records | 使用完整来源范围 |
| Current frame | 按 Apply 时的当前帧冻结查询范围，后续播放不改变该范围 |
| Selected IDs | 按 Apply 时选中的自动 ID 和人工轨迹名冻结身份范围 |
| Kept only | 排除 analysis_keep=0 的记录；未勾选时也纳入这些记录 |
| Apply | 在后台应用条件，接受与当前数据版本一致的结果 |
| Clear | 关闭筛选并解除精确记录编辑作用域，保留条件草稿供再次使用 |

Filter 后的星号表示已启用一个查询。状态行显示匹配行数、范围内总行数和身份数；悬停可读完整文字。数据、人工对齐、标定或相机模型改变后，查询结果需要重新计算。待计算或查询出错时，表格显示原始当前视图，表头保持原色，Use matched rows 和 Select IDs 不可用；这些行不是有效筛选结果。应根据状态行修正并 Apply，或使用 Clear。

Current frame 显示当前帧与筛选结果的交集；IDs 汇总命中记录所属的身份；Selected ID 显示当前身份与筛选结果的交集。Selected ID 的真实 GAP 仍按完整源轨迹判断，不能把筛选隐藏的帧理解为真实漏检。画面上的框和原数据不会仅因筛选而被删除。

### 2.11.2 Rows 条件与 All／Any 分组

Rows 的 Field 菜单包含当前数据中的实际公开列、Record type 及运动派生指标，自定义列可直接参与筛选。内部事务字段不作为普通表格列列出。已有条件引用的列在新文件中不存在时，Apply 报告该列不可用，不自动忽略此条件。

Field 下拉列表可展开至足以阅读完整字段名的宽度。Value 是可输入的下拉框，展开时提供当前列的不同已有值；也可直接输入数值、文本或集合表达式。已有有效筛选结果时，Rows 的建议值来自命中记录，IDs 的建议值来自相应统计结果；尚未计算的派生值不提供候选，仍可手动输入。展开列表不会替换已输入的内容。

1. 点击 + Condition 添加一条条件，选择 Field、Operator 并填写 Value。
2. between／outside 需要再填写 To；其他运算不读取该框。
3. All 要求同一条记录满足全部启用条件；Any 接受任一启用条件。
4. 点击 + Group 建立独立 All／Any 组，选中组后添加其子条件。
5. 取消 Use 复选框可停用该条件或整组；× 删除当前条件或组。
6. 点击 Apply 更新预览。普通输入修改不立即执行查询或修改标注。当前运算所需输入全部为空的普通条件作为未完成草稿忽略，空分组也忽略；不参与当前运算的 To 旧值不使空条件重新生效。is missing、is not missing、is true、is false 仍然有效。将已启用查询的全部条件清空或删除时，自动按当前来源和范围重新显示无条件结果。between／outside 只填写一个边界时仍需补全，非法数值不会被当作零。

Rows／IDs 标签右侧的 Find in table 输入框与 Find 按钮用于文本查找，按 Enter 也可执行。Rows 查找当前 Current frame 或已打开的 Selected ID 表；IDs 查找身份汇总表。按各列显示文本进行不区分大小写的包含匹配，选择并居中定位命中行，重复执行依次查找下一行并循环。查找保留现有筛选限制，不扩大到当前表格未显示的帧或记录，不修改标注。

| 运算类别 | 运算及输入规则 |
| --- | --- |
| 相等与集合 | equals、not equals、in、not in；集合以逗号分隔，包含逗号的文本值用引号包围 |
| 文本 | contains、not contains、starts with、ends with；按字面、区分大小写比较，不执行正则表达式 |
| 数值 | >、>=、<、<=、between、outside；需要有限数值，普通区间包含边界 |
| 空值 | is missing、is not missing；不读取 Value |
| 布尔 | is true、is false；支持常见布尔及 0／1 表示，空值不被当作 false 命中 |

Local direction 与 Segment direction 的区间允许跨过 0°。例如 between 350 和 10 表示向右附近的方向，不是 10–350° 的大区间。未定义数值不会通过普通数值比较；检查这类记录应使用 is missing。

**实例：定位跌落插值及低处异常框。** Rows 设置 `source equals drop_interp`、`y > 600`，根组选择 All。只有同一条记录同时满足这两个条件才命中；某 ID 在一帧属于 drop_interp、另一帧 y>600，并不意味着该 ID 存在符合两项的记录。数据中已经改记为 interp 的旧段不会被推测还原为 drop_interp。

### 2.11.3 IDs 统计与第二阶段条件

IDs 数据表的 Frames 为不同帧号数量，Interpolated frames 为被识别为插值的不同帧号数量。同帧重复框不会重复增加这两项；数量不是末帧减首帧加一。插值判断读取 source、state、position_source 中的插值来源、Trajectory 的 curve_fill，以及明确的 interpolated、is_interpolated、manual_input_interpolated 标志，不把所有 detected=0 直接视为插值。

Filter → IDs 条件在 Rows 条件之后执行。Frames、Interpolated frames、Interpolation %、Maximum speed、Median speed 都根据前一步命中的行计算，再决定保留哪些身份。两种来源的身份分别汇总。

**实例：只检查有较长跌落插值段的 ID。** Rows 设置 `source equals drop_interp`，IDs 设置 `Frames >= 10`。这表示至少有 10 个不同帧符合 Rows 条件；不表示该 ID 的完整轨迹长度不少于 10 帧。如果先增加 `frame between 1000 and 2000`，统计只计算这个范围内的命中记录。

### 2.11.4 运动测量设置与定义

Metrics… 设置测量窗口、单位、坐标空间及是否纳入插值点，确认后应用查询。Window (frames)=1 使用原坐标；较大的值对同一连续段内坐标作居中滑动平均，仅用于测量，不改写实际轨迹。窗口按视频帧跨度确定，不把人工采样间距误当作一帧。

Source 使用原图坐标；Camera 使用已有相机稳定变换后的坐标，需先启用 Camera motion，并具备可用锚点观测或载入的相机变换。px 对应像素单位；cm 需有效 Scale 标定，且标定空间必须与测量空间一致。局部方向使用右方 0°、上方 90°，与原图 Y 向下的存储方向区分。

局部测量按不同帧时刻的坐标计算数值导数，时间为连续解码帧号除以标称 FPS，不把容器 PTS 缺口解释为额外画面。自动标注按连续帧分段；人工采样允许其规则采样间距，显著超过该间距的缺口另起一段。缺失坐标、同身份同帧重复观测及被排除的插值／非保留记录不能作为可靠导数样本。

| 指标 | 定义、单位及边界 |
| --- | --- |
| Speed | 速度向量的长度，px/s 或 cm/s |
| Acceleration magnitude | 速度向量导数的长度，px/s² 或 cm/s² |
| Acceleration X／Y | 加速度分量；X 向右、Y 向上为正 |
| Tangential acceleration | 速率的时间导数；正值加速、负值减速 |
| Local direction | 当前局部速度方向，0–360°；零速时未定义 |
| Segment direction | 连续段首尾净位移方向；闭合或净位移接近零时未定义 |
| Segment displacement | 连续段首尾的直线距离，px 或 cm |
| Segment path length | 连续段相邻有效位置的路径长度之和，不跨 gap 连接 |
| Segment tortuosity | 路程／净位移；净位移接近零时未定义 |
| Turning angle | 连续两段位移的方向变化绝对值，0–180°；段端点及静止邻接处未定义 |
| Curvature | 局部平面曲率，1/px 或 1/cm；零速及采样不足时未定义 |
| Segment mean speed | 路程／连续段持续时间，px/s 或 cm/s |

只含一个点的段不足以给出局部运动；只含两个点的段可测位移与速度，不能给出可靠加速度和曲率。测量平滑可以降低毛刺影响，同时也会减弱真实急转和短暂加速，应结合图像验证。

运动指标先按完整连续源段计算，再应用 Rows、帧及身份范围条件。因此，`frame between 100 and 200` 不会把完整连续段的 Segment path length 或 Segment direction 重新定义为 100–200 帧的几何量。Maximum speed／Median speed 则在命中行上汇总局部 Speed。不同指标的范围含义不得混用。

**实例：定位跳框。** 使用 Source、px、Window=1，Rows 设置 `Speed > 800`，先查看 Current frame 和 Selected ID 命中帧，再播放其前后段。若原图运动主要来自相机，应先启用 Camera 并选择 Camera 坐标后复查；不能直接把相机位移解释为目标速度。

### 2.11.5 精确记录编辑与整条身份选择

启用筛选只改变预览。Use matched rows 与 Select IDs 的含义不同：

| 动作 | 后续修改范围 |
| --- | --- |
| Use matched rows | 冻结命中的自动行 UID 与人工采样点身份；Delete 和 Change class 只作用于仍存在的这些记录 |
| Select IDs | 选择命中结果所代表的完整身份，解除精确记录作用域；后续使用普通 ID／Range 规则 |

Use matched rows 按钮保持按下并显示冻结数量。公共 D 与 Box → Delete 均使用此精确范围；其他 Edit 工具须先解除它，防止插值、合并或位置添加误用筛选记录。再次点击 Use matched rows、Clear、Select IDs，或直接编辑公共 ID／Range，可解除该作用域。删除后不存在的记录不重新创建；重新 Apply 可取得新的命中集合。

**精确范围示例：** 查询只命中 ID 1 的第 100 帧与 ID 2 的第 200 帧。Use matched rows 后 Delete 只删除这两条记录，不连带删除 ID 1 的第 200 帧、ID 2 的第 100 帧，或同帧另一条未命中的重复框。命中人工点时也按名称、对齐帧和采样点序号定位，不按整个名称批量扩大。

一次精确删除或改类作为一次提交，可经主 History 撤销／重做；混合自动与人工来源时一次撤销恢复双方。筛选条件、预览切换和浏览动作本身不进入标注 History。条件与精确作用域只在本次程序会话内使用，不改变 SQLite 架构。
