# 5 Edit 操作说明

[返回总目录](00_操作手册.md)

## 5.1 范围与共同输入

本册说明 Box、ID、Interpolate、Swap。Trajectory、Scale、Points/Events 各有独立分册。Edit 顶部的 ID、Range、x/y/w/h 为操作输入；它们与当前画面选择相关，但输入本身不立即改写标注。

ID 可输入指定身份；All IDs 将范围扩展到全部身份。Range 使用视频帧号，支持单帧、闭区间及逗号分隔多个区间，例如 `120-150,180,200-230`；All frames 指全部有效帧。批量操作前先检查这两个开关，避免把本意的一帧修正应用到整个视频。

x/y 为框中心、w/h 为尺寸，单位是原图像素。仅改变显示缩放或平移不会改写这些值。Link selection 控制一般选择与相关身份/范围的联动；显式输入后应以最终显示的 ID/Range 核对操作范围。

## 5.2 Box：按空间范围选择

### 5.2.1 选择规则

| 设置 | 规则 |
| --- | --- |
| Center | 框中心落入皮筋框时选中 |
| Contained | 整个标注框包含在皮筋框内时选中 |
| Intersects | 标注框与皮筋框相交时选中 |
| Accumulate | 将新结果加入已有选择，而不是替换 |
| Over time | 在时间范围内查找进入此空间区域的标注，不只看当前帧 |

点击 Select 后在画布拖出矩形。范围选择只筛选对象和帧，不修改框坐标。密集目标应优先使用较小区域，并检查结果表；区域中不同时间出现的目标不一定是同一个体。

**Over time 选择模式的身份与时间限制独立判断，可以分为两步理解：先确定在哪里搜索，再决定选中哪些记录。**

点击 Select 时记录本次搜索范围；后续 Accumulate 追加框选沿用这一范围，不会因上次选中结果改变 ID／Range 而自动缩小搜索。未勾选 Over time 时只检查当前帧，下面的跨帧规则仅用于 Over time 模式。

**第一步：搜索限制。** ID 与时间分别判断，两个限制同时满足的记录才参与空间匹配；已删除的标注不参与搜索。

| 输入 | 搜索哪些记录 |
| --- | --- |
| All IDs 开启，或没有指定／选中身份 | 不限制身份 |
| All IDs 关闭，且有指定／选中身份 | 只检查这些自动 ID 或人工轨迹 |
| All frames 开启 | 不限制搜索帧 |
| All frames 关闭，Range 为空／只有单帧，或仅列出离散单帧 | 搜索全部帧；单帧输入不作为跨帧搜索限制 |
| All frames 关闭，Range 至少含一个连续区间，如 `100-120,150` | 只搜索所列区间及单帧的并集 |

例如 Range=`100` 时会跨全部帧查找，不只查第 100 帧；Range=`100-120` 时仅搜索这 21 帧。这是当前工具区分“当前帧输入”和“跨帧区间”的规则。进入框选后状态栏会显示实际搜索范围，框选前应核对。

**第二步：选中结果及后续编辑。**

- All frames 关闭：只保留各 ID 实际满足矩形条件的那些标注记录，公共 Range 显示这些帧段的并集，黄色条带显示同一局部范围。不会因为一帧进入矩形，就选中整个 ID。紧接着执行删除、改类、改号或几何修改时，按这些记录处理。
- All frames 开启：矩形用来找出身份，后续按这些身份的全部帧处理。此时不保留“只有进入矩形的帧”这一局部限制。
- Accumulate 开启：把新匹配记录追加到已有选择；关闭时用新结果替换原选择。

退出 Choose range 不改变 All frames。其他选择或输入可能改变后续编辑作用域；需要连续执行多次修改时，重新框选并核对 ID／Range。Raw／后处理预览的数据层另见 [Detection 分册](04_Detection后处理测试操作说明.md)，不应混同为审阅主表。

快速拖框按鼠标松开的位置结算。矩形过小、坐标无效或区域没有匹配对象时，状态栏说明原因，并保留原有选择；不会把失败操作报告成成功选中零个 ID。

### 5.2.2 实例：静止蜜蜂消失后换 ID

1. 找到蜜蜂最后存在的帧，确认其位置。
2. 在 Box 选择 Center，勾选 Over time，并启用 All IDs 或清空原 ID 限制，再在该位置画一个小范围；必要时限制 Range 到消失前后。
3. 在 IDs/Selected ID 查看选出的旧、新身份及连续段。
4. 跳到旧身份尾帧和新身份首帧，检查目标是否确为同一只。
5. 进入 ID，将旧身份作为 Target，新身份作为 Source；确认后 Merge。
6. 需要填补消失段时启用 Interpolate between，再逐帧检查中间区域是否仍合理。

## 5.3 Box：Change position

### 5.3.1 四种几何模式

| 模式 | 交互 | 保持的量 |
| --- | --- | --- |
| X/Y | 指定新中心或移动位置 | W/H |
| W/H | 调整框尺寸 | 中心位置 |
| X/Y/W/H | 拖动中心/边缘进行综合调整 | 未操作部分按交互约束保持 |
| Draw | 在画布重新画出目标框 | 用新矩形确定中心和尺寸 |

先选择 ID 和 Range，再点击 Change 进入相应模式。检查画布的交互框及顶部几何输入，确认新位置后执行 Apply。框的中心位置使用原图坐标；Camera 稳定视图会经过显示与原图之间的转换。

### 5.3.2 Continuous、Auto next 与退出

Continuous 未勾选时，一次成功修改后退出编辑模式，勾选时可连续修改。Auto next 只在 Continuous 启用时用于在成功暂存操作后切到下一帧，方向跟随整体播放方向控制。Apply 或 Enter 提交时保持当前帧，不额外执行 Auto next。

在编辑模式中，未设置所需位置时点击 Apply 会退出，不生成空几何修改。ESC 退出交互。编辑中切换 Continuous 的勾选状态也结束当前编辑模式。结束时应核对实际已应用的点；退出交互不应被当作撤销已经完成的操作。

Continuous 会话中使用轻量局部撤销，可逐步退回本次位置指定；会话结束后的 History 操作按该会话的提交边界管理。输入框正在编辑文字时，Ctrl + Z 优先属于文字编辑，不宜用来判断轨迹撤销状态。

位置指定后 trail 立即反映待提交坐标。已有点的修改只重新计算受影响的邻近曲线，保留其他段的几何缓存；增删点改变连续段结构时，重建受影响目标的缓存。切帧仍按 Before / After 设置显示相应部分，局部撤销、重做同步恢复或更新轨迹。

Continuous 编辑保持开启时，在画布右键仍提交当前帧的位置指定，不受当前显示的主选项卡或 Edit 子选项卡限制。新增帧立即加入选中 ID 的黄色出现范围，本次会话新增范围以绿色条带标示；仅移动已有框不新增绿色范围。局部撤销、重做和会话提交同步刷新条带。单次编辑时绿色标示最近一次新增结果，其他数据编辑后不沿用旧标示。

### 5.3.3 Confirm 与类别修改

Confirm 为三态控件，控制 Change position、Change class 与 Delete 执行前是否弹出确认窗口：勾选时三种操作均需确认；中间态仅 Change class 和 Delete 需要确认；未勾选时三种操作均不弹出确认窗口。它不设置标注行的人工确认状态。

选择 Change class 的类别后点击相邻 Change，将类别应用于目标范围。Delete 删除作用范围内的标注；它不删除视频和磁盘原始文件，也不负责删除 Tracking 尚未提交的整个区间。

Change class 的展开列表只包含 INI 配置的类别。控件本体汇总所选身份在工作表中的类别：全部为同一类别时显示该类别，包含两种及以上类别时显示 multiple；该提示不作为可选类别加入列表。统计按身份与数据修订缓存，不随播放或每次展开列表重新扫描操作 Range。实际修改仍遵循所选 ID、Range 及 All frames。

启用相应 Confirm 策略且未勾选 All frames 时，Change class 和 Delete 的确认窗口显示 `Current Range is not All frames.`。Yes 仅执行当前 Range；Apply on all 对当前身份执行全部帧范围，不改写公共 Range 或 All frames 的显示状态；No 或关闭窗口不修改数据。关闭 Confirm 时直接按原范围执行，不额外拦截。按 Alt + C 可在类别列表中循环切换已选目标的类别，遵循同一范围与确认规则。

Edit 公共区域的 D 按钮与 Box 的 Delete 完全等效，使用相同 ID、Range、All frames、确认设置和撤销规则。它与 Interpolate 的端点区间 Delete 使用不同的作用范围。

Confirm edit 的操作明细较长时使用可滚动的只读文本区，可选择、复制正文。`Current Range is not All frames.` 与 `Apply this command?` 固定显示在文本区外，底部按钮不随正文滚动。询问 `Current Range is not All frames.` 时窗口默认焦点位于 Apply on all；其他确认窗口默认焦点位于 Yes。关闭窗口或选择 No 均取消本次操作。

## 5.4 ID：合并与改号

### 5.4.1 Merge ID

Target 是保留的身份，Source 是并入的身份，点击 Source 可交换 Target 与 Source 输入。Select 用于画面点选身份对，Clear 清空 Source，Clear all 清空这组身份输入。时间轴的蓝色、绿色条带分别对应 Target 和 Source，红色表示同时存在的帧。

Source 允许多个 ID；Target 必须为单个 ID。双击 Source 输入框会在其下方展开可滚动的迷你输入 ID 表，原框仍可正常选择文字、复制和粘贴。迷你表支持 Ctrl／Shift 多选、Ctrl + A 全选；单击行会选中身份并跳到其就近出现帧，公共 ID、画面和表格高亮同步更新。在迷你表按 Delete 只从 Source 输入中移除所选 ID，不删除标注；Esc 隐藏迷你表。当前选项卡为 ID 子页时，Target 对应框加粗蓝色描边，Source 对应框加粗绿色描边，填写或删除输入后立即更新。该描边只用于此页的编辑提示，不改变保存的标注或其他页面的显示样式。

按键盘快捷键 **M** 将当前活动自动 ID 加入这组输入：Target 为空时先填 Target，否则追加到 Source，重复按不会移除。按键盘快捷键 **N** 从 Source 中移除当前活动 ID，但要求该 ID 仍被选中且在当前帧存在。M／N 不执行合并，输入与条带立即更新；文本框内保留正常文字输入。

Merge 的主要工作是统一身份。它不会自动判断两个同帧框究竟哪个对应真实目标，也不能用来掩盖两个同时存在的不同个体。出现冲突时先检查相关帧，必要时缩小范围、删除重复框或使用 Swap。

Interpolate between 复选框用于补齐相应身份段之间的空档。勾选后，按所列 Target／Source 身份的完整出现段寻找空档并插值补齐。插值不受公共 Range 限制，但 ID 合并本身仍遵循当前 Range 或 All frames。例如 Target 在 100–120 帧、Source 在 140–160 帧，Range 为 140–160 时，合并 Source 的同时仍补齐 121–139 帧。

#### 自动寻找可接续的片段

1. 在当前帧选择要接续的框，通常定位到断点附近。可保留原 Target／Source；搜索不要求 Target 仍在当前帧出现，Target 为空也可搜索。
2. 点击 **Find**，打开 **Merge fragment candidates** 窗口。窗口打开时不夺取焦点；阈值框可点击并直接输入数字，操作按钮或候选行后焦点回到播放，Space 控制播放／暂停，R 控制倒放。
3. 模式选 **Continuity**。方向跟随 Reverse 状态：关闭时为 **Forward**（更晚帧），开启时为 **Backward**（更早帧）；窗口打开期间更改 Reverse，Direction 立即更新，也可手动选方向。每次 **Search** 从当前选中框的实际帧号和 xywh 搜索，将新候选追加到列表；不使用 Target 的历史位置。相同候选不重复加入，Batch 持续递增。窗口显示 Searching…，结束后显示新增数与总数，没有新结果也会明确提示。
4. 单击候选行会选中其 ID，并跳到该片段内离当前帧最近的位置，公共 ID、画面高亮和 trail 同步更新。Ctrl／Shift 可多选，Shift 按当前表格排序选择连续行。双击列标题排序，默认按 Range 升序。
5. 搜索沿唯一接续链前进，在第一个存在多个可能接续的位置停下。唯一链的候选默认勾选 **Use**；分叉候选默认不勾选，除 ID 列外文字显示为红色。保留一个分支起点、用 **Remove** 删除其他分支行后，按 **Continue** 从保留片段的端点继续，结果追加到原列表，Batch 列区分搜索批次。无需分支选择的链尾也可 Continue。
6. **Use／Unuse／Remove** 只作用于选中行。**All rows** 选中表内全部行，同时在主窗口选中这些 ID；不改变 Use 状态。Use 状态决定哪些 ID 会由 **Fill candidates** 追加到 Source；Remove 只删除候选行，不删除标注，也不改已填入 Source 的内容。勾选 **Select all candidates** 会在主窗口选中全部候选 ID、显示高亮和 trail，但不把候选表整表选中。点击主画面改选后，复选框随实际选中 ID 更新。
7. 回到主窗口核对公共 Range／All frames，再点击 **Merge**。搜索、继续、排序、定位、勾选与填入均不修改标注。

搜索从当前选中框的位置向指定时间方向出发。沿已知同 ID 的连续段前进时，使用该段真实端点的位置；找到唯一接续候选后，再使用新片段的端点位置继续查找。不把起点位置一直套用到很久以后的帧，也不从 Target／Source 中遥远的历史段重新起搜。同一 ID 内时间和距离均接近的小 gap 可以继续通过。

每次 Search 也将选中 ID 的参照片段列入表格，Use 默认开启，悬停可辨认参照行。Continuity 列出从当前帧沿方向的本段；Duplicates 列出方向与 Range 内的实际参照片段。Continue 只追加接续结果，不重复增加参照行。

| 参数／列 | 含义 |
| --- | --- |
| Max gap frames | 相邻片段之间允许缺失的帧数，默认 **5 帧**，与视频 FPS 无关；0 表示只接受没有缺帧的相邻片段 |
| Distance (× diagonals) | 相邻端点的框**中心**距离，除以这两个框对角线长度的平均值；默认 **0.4 倍**。例如两框均为 30×40 像素，对角线为 50 像素，则允许中心距离不超过 20 像素。Distance 列同样显示该倍率，不受画面缩放影响 |
| Overlap frames | 允许的少量重叠帧数，默认 5；候选仍须向所选方向延伸 |
| Frames | 该连续片段的帧数，包含首尾 |
| Gap | 正数为缺帧数，0 为紧邻，负数为重叠帧数 |
| IoU | Duplicates 模式中两框交集面积／并集面积的均值，越接近 1 表示重叠越多；Continuity 不使用 |
| From ID | 本候选从哪一个身份片段接续而来 |
| Batch | 本次窗口内搜索批次，Search 和 Continue 都递增；重复找到的候选保留原批次 |

Continuity 只搜索同 Class 的片段。ID 列在 Use 左侧，数字加粗并使用身份分配颜色；行底纹与对应条带使用循环配色区分片段，条带旁数字是候选 ID，使用该 ID 的颜色。当前帧所在行居中，序号格以黄色标出；没有候选覆盖当前帧时，用黄色细线标示其时间位置。点击行也会精确居中，方便在同一相对位置连续点击上一行／下一行。切帧始终保留人工单选或多选；黄色定位和 Use 勾选独立，不会自动勾选或执行合并。窗口关闭后恢复普通 Merge 条带。

**例如：** ID 1 在第 100 帧结束，ID 2 在 102 帧附近原位置出现，缺失 1 帧；在第 100 帧向前搜索可找到 ID 2。若 ID 2 随后移动到别处并在 130 帧结束，下一步使用它在 130 帧的位置寻找接续 ID，不使用第 100 帧的位置。搜索结果只是建议，附近另一只同类目标仍可能被列为候选。

Fill candidates 只填入候选 ID。最终 Merge 仍按公共 Range／All frames 执行；一个 ID 在其他时段也有记录时，务必核对范围，避免将全部时段一起并入。

#### 查找同帧重复框

在同一个 Find 窗口把模式切到 **Duplicates**，以选中 ID 在公共 Range／All frames 内的实际框为参照，逐帧检查其他 ID。Direction 可选：Forward 搜索当前帧及以后，Backward 搜索当前帧及以前，并始终受 Range 限制。此模式不使用接续片段的时间 gap 或允许重叠帧数。

搜索区域是随参照框逐帧移动的矩形。**Area W/H (× diagonal)** 为矩形的完整宽、高，分别乘以该帧参照框的对角线长度，默认均为 1.2；候选框中心落在矩形内才纳入。**x/y offset** 的两个整数框定位矩形中心相对参照框中心的像素偏移，向右／向下为正，默认 0。例如参照框 30×40 px，对角线为 50 px，W=2、H=1 对应 100×50 px 的搜索矩形。

Duplicates 模式使用矩形宽高，而不是 Continuity 的 Distance 距离门槛，不再叠加圆形距离限制。Duplicates 表中 Distance 是候选中心距偏移后搜索中心的距离，除以该帧参照框对角线长度，只用于比较。

**IoU ≥** 是可选的额外条件，默认开启、阈值 0.30。它按原始两框的交集／并集计算，与 X/Y 偏移可同时使用；但找分离的框时应关闭，否则会因没有重叠而排除。**Same class** 默认开启，取消后也查找其他类别。例如找胡蜂右侧约 30 px 的棍子误检框，可关闭 IoU，设置 X=30、Y=0，再调整 W/H 和 Same class。搜索将满足条件的帧拆成连续片段；候选仍需人工判断。

其他重复框候选的 Use 默认关闭。可选择候选行，或勾选 Use 后按 **Use matched frames**：将这些候选各自的匹配帧作为局部选择，公共 ID 为候选身份、Range 为帧段并集，Target 填参照 ID，Source 填候选 ID，并关闭 Interpolate between。参照行始终排除在此清理作用域之外，即使与其他行一同选中也不会删除参照本身。此时 Delete 仅删除匹配的候选记录，Merge 仅合并各 Source 自己的匹配帧；出现同帧冲突时仍要选择保留哪一个框，不会移动框或修改 Raw ID。

同一列表可追加多批搜索结果。使用匹配范围时，一次选择同一个参照 ID 的重复候选；From ID 列可核对参照身份。继续改公共身份、Range、All frames 或数据后，原局部选择失效，应重新使用 Use matched frames。若明确改用 All frames／Apply on all，则按整个身份处理。

公共 **ID**、公共 **Range** 和 Merge **Source** 输入框均可双击展开迷你表，再次双击同一输入框或按 Esc 收起；原输入框仍可复制粘贴。ID／Source 表支持单击定位及 Ctrl／Shift 多选。Range 表按输入中的帧段逐行列出，选中行可把这些段填回公共 Range 并关闭 All frames，单击定位到所点帧段；切帧不重新解析并收缩列表。Source 迷你表中的 Delete 只移除输入项，不删除标注；公共 ID／Range 迷你表不绑定 Delete，以避免误删。

#### 确认范围与处理重叠

点击 Merge 后**先确认范围，再处理冲突**。未勾选 All frames 时，Yes 使用当前范围；Apply on all 使用所列身份的全部帧，但不改写公共 Range 或 All frames 控件。选择后不会重复弹出范围确认，也不会因扩大范围而重新询问已经处理过的一批冲突。

冲突同时检查 Target 与 Source、不同 Source 之间的重叠。**IDs overlap** 窗口显示当前序号／总数及帧段，提供五个按钮：

| 按钮 | 动作 |
| --- | --- |
| Goto range | 跳到本冲突段首帧；窗口保持打开，不改变已确认的合并范围 |
| Keep ID xxx | 保留该原 ID 在本冲突段中的框记录，删除另一方的重叠记录；合并后仍统一命名为 Target |
| Keep ID yyy | 保留另一方的框记录，规则相同 |
| Skip range | 保留当前冲突段所有原 ID 与标注，跳过该段，继续处理后面的冲突；关闭窗口或按 Esc 同样跳过。此前在本段做过的选择也不执行 |
| Cancel merge | 取消整次合并，之前的冲突选择不会部分写入 |

窗口不占用主窗口焦点，可以切帧预览。红色条带覆盖上述各类冲突。同一段有三个及以上 ID 时，要逐次决定保留者，因此同一帧段可能有多个不同身份对的询问；序号／总数按实际需要的选择次数显示。所有冲突选择完成后，合并、冲突删除和可选补间一次提交，可整次撤销。

### 5.4.2 Change entire 与 Change range

在 Change ID 输入目标编号。Change entire 用于整条所选身份改号；Change range 只对指定范围改号，可把一段从原身份拆出。目标编号已存在时应处理重叠冲突，不把“输入成功”等同于“每帧唯一”。

允许将多个所选自动 ID 一次改为同一编号；未选择的身份不受影响，整次改号可作为一步撤销。执行前检查目标编号与各来源、以及不同来源之间的同帧重复。目标编号仅在其他不重叠帧出现时不产生重复警告；确实会产生同帧多框时列出冲突帧并询问是否继续，取消则不执行任何部分。

Duplicate ID 的 Find 用于检查同帧同 ID 的重复行。先定位重复帧，再根据图像判断保留哪一个。相同 ID 在不同帧出现是正常轨迹，不属于重复冲突。

**例：ID 25 的后半段串到另一个体。** 将串号开始到结束的范围设入 Range，使用 Change range 分离这段，再与实际身份核对；如果两条轨迹在同一时刻互换，使用 Swap 更直接。

## 5.5 Interpolate：两端几何与补间

### 5.5.1 控件与计算

A/B 各包含 frame、id、x、y、w、h。Selected as A/B 将当前选中框的几何和帧号写入对应端点；也可以修改字段。A/B 时间顺序可倒置，执行时按实际帧号排序。

点击行首 A: 或 B: 可跳转到对应端点。有效 frame 用于精确定位，已存在的 id 用于选中自动身份或整条人工轨迹，两项分别判断；缺少、格式无效或不存在的项目静默跳过，不弹出错误窗口。身份在目标帧缺失时仍可保持选中该身份，并定位到输入帧，不自动改跳到其最近出现帧。例如 frame=400、id=7，ID 7 只在 390 帧前和 410 帧后出现，点击仍定位至 400，便于检查空档；只填 id 时保持当前帧，只填 frame 时保留当前选择。

左下角 C 按钮清空 A/B 两行的全部输入、缓存端点几何及相应进度条标记。

录入端点不要求一次提供全部信息。没有选中框或人工点时仍记录当前帧，只有已选 ID 时同时记录身份；坐标和尺寸可随后补充。更换帧或身份时，不沿用其他端点观测的旧几何。执行 Interpolate interval 时才检查所需信息是否完整。Interpolate 页面在进度条下方以 A／B 字母标示已填写的端点帧，点击可定位；切换到其他页面后隐藏标记。

在同一段内，以帧位置比例对中心和尺寸作线性插值。例如第 100 帧中心 (100, 50)，第 110 帧中心 (120, 70)，第 105 帧估计为 (110, 60)。该模型表示两端之间按时间线性变化，不保证真实轨迹为直线。

### 5.5.2 实际执行范围

1. 两端 ID 不同时，会先询问是否把 B 的身份合并到 A；拒绝则不继续该插值。
2. 存在内部 gap 时，使用已有几何分段补缺，不把整段可靠观测简单压成 A/B 一条直线。
3. 选择范围伸出已知首尾时，利用最近几何及显式端点字段构造外侧边界。外推式补点应人工检查。
4. 区间已经完整、没有可补 gap 时，会询问是否用 A/B 替换该区间；这是重建区间，不是只补缺失。
5. 没有可用几何或不足两个有效端点时，不能完成插值。

若 A/B 的 frame 未全部填写，且两个 id 框中只提供了一个自动 ID，或两框填写同一自动 ID，点击 Interpolate interval 会补齐该 ID 整条轨迹中有两端有效观测的所有 gap，不使用公共 Range，也不使用已填写的单个 frame 限制范围。原有观测保持不变，不向轨迹首尾外侧延伸；没有 gap 时不改动数据，也不询问是否改写完整轨迹。例如 ID 7 在 100–120 和 130–150 帧出现，只填 id=7 即补齐 121–129 帧。A/B 的两个 frame 均已填写时，继续按下面的区间规则处理。

### 5.5.3 实例一：短漏检段

目标在 200–220 帧存在，221–225 缺失，226 帧重新出现且身份已确认。

1. 从 Selected ID 定位 220，Selected as A。
2. 定位 226，Selected as B。
3. 核对类别、尺寸及中间是否遮挡/急转。
4. 点击 Interpolate interval，检查 221–225 的结果。
5. 结果来源属于插值；不要把这五帧计为模型实际检测成功。

### 5.5.4 实例二：完全没有标注的区间

1. 为目标确定一个新 ID。
2. 使用 Change position 的添加流程或 Tracking，在 100、110、125 等关键帧指定框。
3. 确认这些关键帧使用同一 ID。
4. 用 A/B 覆盖目标区间执行插值，让已有关键帧作为分段边界。
5. 在快速转弯、遮挡前后增加关键帧再检查；不要跨过不可判断的长遮挡直接假定直线。

### 5.5.5 实例三：位置错误但每帧都有框

选择错误段前后两个可靠端点，执行插值时确认替换区间。这样可以消除一段错误位置，但也会覆盖该区间原有运动细节；有弯曲路径时优先使用 Trajectory Edit/Draw。

### 5.5.6 删除 A/B 内部错误段

1. 将可靠的前后帧分别记入 A/B，核对目标身份；两端时间顺序可倒置。
2. 点击 Interpolate interval 旁的 Delete，检查窗口中的 A–B 范围。
3. 两端身份相同或只有一端填写身份时自动带入该目标；身份不一致或均为空时，选择或填写本次目标 ID／已有人工轨迹名。
4. 默认保留两端，仅删除内部帧。需要连同端点删除时勾选 Include endpoints。
5. 点击 Delete 执行，检查结果；需要恢复时撤销本次操作。

该 Delete 仅读取 A/B 与窗口中明确指定的目标，不读取公共 ID、Range、All frames，也不要求端点几何完整。例如 A=100、B=110，目标为 ID 7，默认只删除该 ID 的 101–109 帧，其他身份及公共输入保持独立。取消窗口或两端之间没有内部帧时不修改数据。整个删除作为一次相应数据来源的撤销操作。

## 5.6 Swap：身份交换与按位置纠正

### 5.6.1 输入、预览与提交

模式下拉框提供 **Exchange** 和 **Position** 两种模式选择。Begin／End 各有一个 frame 与 ID 列表框。ID 框可填入至少两个身份，例如 `001,002` 或 `001,002,003,004`，两行须填写同一组身份，身份填写顺序和帧顺序可倒置；Exchange 模式只允许两个 ID，Position 模式允许两个及以上。

**Selected as Begin／End** 允许分次录入：没有选择时先记当前帧，单选时补充该身份，多选时填入这组身份。执行前才检查完整性。点击行首 **Swap Begin:／Swap End:** 跳到有效 frame 并选中已有身份；缺失、无效或不存在的项目独立跳过，不弹窗。左下 **Clear** 清空这两行、临时端点和中间锚点，不改标注或其他工具的输入。

**Preview** 为身份修正的预览开关。按下后按钮保持按下状态并在后台计算；再次按下取消。修改模式、端点、ID、范围等输入会使原预览失效，应重新预览。预览只显示拟议结果：框不移动，橙色标签说明原 ID → 结果 ID，紫色 `ID ?` 表示不确定；时间轴分别以橙色 Changed、紫色 Uncertain 条带定位。

**Swap A ↔ B** 是最终提交按钮。Exchange 模式可直接提交，也可先 Preview 再提交；Position 必须先得到预览，且存在可修改项时才能提交。提交后预览退出；整次修改可撤销。不确定的帧默认跳过，不会强行交换。

### 5.6.2 Exchange：完整区间内交换两个 ID

Begin 与 End 是实际交换区间的边界，包含两端；两帧相同可以只交换一帧。Exchange 使用这两行的区间，不使用公共 Range 代替边界，也不使用 Position 的中间锚点。

1. 找到身份互换的第一帧，选择两只目标，Selected as Begin。
2. 找到需要交换的最后一帧，Selected as End。
3. 核对两行是同一对 ID，可按 Preview 检查标签及橙色条带。
4. 点击 Swap A ↔ B，确认并检查两端交接。

**例如 1000–1040 帧两只目标的 ID 始终反了：** 使用 Exchange 模式交换整段；若只有零散帧错误，不应把所有正确帧也交换，应使用 Position 模式。

### 5.6.3 Position：纠正零散、反复或多目标串号

此模式根据首尾可靠帧的二维相对结构和中间短时运动连续性，为每帧计算一对一身份分配，并要求从两端推导的结果一致。它不是按全局横坐标排序，也不把首尾位置连成直线替代中间轨迹。

1. 在公共 ID 中选择要参与纠正的两只或多只目标，明确要检查的范围。
2. 在错误范围之前，找一个这些目标**身份均正确、每个 ID 恰有一个框**的帧，设置 Begin。
3. 在错误范围之后，找另一个身份正确的帧，设置 End；两行填相同 ID 集合。
4. 选择 Position，点击 Preview，沿橙色与紫色条带检查画面和结果标签。
5. 需要更多约束时点击 **Anchors**，在 Intermediate anchors 页点击 **Add current frame**，加入已核对正确的中间帧；可直接修改帧号和身份列表，也可 Remove。修改后重新 Preview。
6. 在 Anchors 的 Preview details 页查看 Changed／Uncertain 段及原因，双击相应段跳到首帧。
7. 确认后点击 Swap A ↔ B，仅提交可明确判断的错配；原本判定正确的帧不改，不确定帧跳过。

首尾及中间锚点帧均保持不变。未勾选 All frames 且公共 Range 含连续区间时，该范围进一步限制要修正的帧；Range 只有单帧或没有连续区间时，使用首尾锚点之间的范围。All frames 不会使 Position 超出锚点边界或扩散到未列出的其他 ID。

目标缺失或同 ID 多框、两框接近重合、帧间路径交叉、运动突变、首尾结构矛盾、双向分配不一致等情况标为 Uncertain。真实交叉、遮挡或明显转动时，可以添加中间锚点，或拆成更短区间检查；不能只依赖几何关系确认被遮挡个体的真实身份。

**例如 A、B 的正确 ID 是 001、002，仅在 101、103、105、108–112、115 帧反复串号：** 使用身份正确的第 100、116 帧作为锚点，Range 设为 `101-115`，两端 ID 都填 `001,002`。Position 会尝试只修正其中明确错配的帧，保留其他正确帧。四只相邻目标发生连锁串号时，可填入四个 ID，通过同一套预览检查；其他未列出的目标不参与。

Position 模式只修改结果身份，不移动、添加或删除框，不改变 Class 或 Raw ID。它处理当前已载入的审阅标注；Detection 的 Raw／临时后处理预览需先 Load result，避免把其他数据层当作主表修改。

## 5.7 操作暂存

### 5.7.1 建立和查阅草稿

Edit 公共区域右下角的 R 按钮打开非模态 **Operation stash**，包含手动草稿和自动操作输入记录。记录按视频路径隔离，保存在当前 recovery 目录的 `operation_stash` 子目录，关闭窗口、关闭视频或重新启动后仍可查阅；不写入标注 SQLite 或 settings.ini，也不进入标注 History。

自动记录完整相关输入组：公共 ID／Range、Merge、Change ID、Change position、Change class、Interpolate、Swap、Trajectory 端点、Tracking 身份、Match 绑定及 Notes。完成输入、执行或清空前保留内容，连续输入合并，停留约 0.8 秒或移开焦点后记录；不逐键保存，不记录 Display／Decoder 等参数，也不因播放自动更新 Range 而记录。每个视频最多保留 1000 条自动记录，手动记录不自动淘汰。

Source / name 默认使用可读来源加序号，例如 `Merge ID #0012`；Time 显示记录触发时间，Type 区分 Manual／Automatic。顶部可按类型、来源、文字以及 From／To 时间范围筛选；时间框直接输入，时间在前、日期在后，不弹出日历。双击表头排序，默认按时间从新到旧。**Restore inputs** 回填记录所属整组原始输入，包括未填完的文字，不执行标注操作。自动记录不直接改写；需要追加或整理时用 Store 建立手动草稿。

| 动作 | 保存内容 |
| --- | --- |
| New | 使用当前公共身份在当前帧新建并选中草稿，不读取公共 Range 作为起点 |
| Connect | 将当前帧与所选草稿上次记录的点连接成闭区间，合并重叠及相邻范围；保留该草稿原有目标 |
| Add point | 只将当前帧追加为一个点，不填补与上次记录点之间的空档；此点成为下一次 Connect 的起点 |
| Store：Range | 将当前公共身份、Range、All IDs／All frames 状态存入所选草稿；单一目标的单一区间可记录已有端点几何 |
| Store：Endpoints | 将当前 Interpolate A/B 或 Swap Begin/End 存入所选草稿；两端帧号必须有效，其余字段可不完整 |
| Store：Segment | 存入当前活动身份中包含当前帧的连续段；当前帧不在可用段内时提示重新定位 |

来源下拉框默认 **Focused inputs**，读取主窗口最后获得焦点的操作输入所属整组内容。例如在 Interpolate 的 x 输入框中操作后，Store 同时记录 A/B 的帧号、ID 和位置尺寸；在 Swap 输入框中操作后记录整组 Begin/End。Interpolate、Swap 的单端或未填完整的内容可先作为草稿保存；没有有效帧号时以当前帧作为暂存定位位置，不代替原输入。下拉框也可明确指定来源，包括 Tracking、Match binding 和 Notes。

**Store** 替换所选手动草稿；**Append** 将来源的身份和区间加入所选手动草稿，合并相邻或重叠区间，不填补分离区间之间的空档；未选中手动草稿时两者均新建记录。追加端点组时保留最前和最后的有效端点，Range 仍保留全部区间。已有专用参数在追加时保留，原来缺少的参数可由新来源补充。New 始终另建记录；自定义名称在后续记录点、Store 和 Append 时保留。选中手动行持续作为 Connect／Add point 的编辑目标，不因主窗口拖动进度条或更换公共 ID 而自动切换目标。

**规程示例：** 在第 100 帧选择 ID 7 后点击 New，定位到 120 帧点击 Connect，得到 100–120。定位到 200 帧点击 Add point，得到 `100-120, 200`；再到 210 帧点击 Connect，得到 `100-120, 200-210`。这些动作只组织操作范围，不生成中间标注点；随后 Use range 或 Send，再执行相应编辑工具。

**Inputs** 按输入位置分区：公共 ID 是一部分，Merge 的 Target／Source 是两部分，Interpolate、Swap 的两端 ID 也分别保存。使用 `|` 分隔，例如 `112 | 123,125-126`；悬停可查看每部分的名称和全文。Append 分别向对应部分追加，不把 Target 混入 Source。

双击手动记录的 Source / name、Inputs 或 Range 可修改名称、输入或帧范围。Inputs 各部分支持自动 ID、ID 列表及人工轨迹名称；Range 使用公共范围的表达式，例如 `100-140, 200-220`。修改身份会取消该草稿原有 All IDs 状态；修改范围会取消原有 All frames 状态。无效范围不替换已保存值。

选中行以黄色显示。列宽可拖动调整，关闭窗口时写入 `settings.ini` 的 `tables/operation_stash/column_widths`，再次打开或下次启动恢复。排序后仍以草稿的稳定身份执行编辑和记录点，不使用排序后的显示行号替代原记录。筛选隐藏了所选记录时，不继续对隐藏记录操作。

修改 Inputs 或 Range 后，原有端点几何和 Merge 专用字段清空，帧端点的画面引用重新建立，防止旧坐标被带入新目标或新帧。后续 Send 到端点工具时，应重新核对并补全位置；目标已不存在时仍可恢复或 Send 草稿，不弹出阻断窗口；可在目标工具重新指定身份。

× 或列表中的 Delete 键只移除选中的暂存条目，不删除标注。编辑单元格文字时，Delete 保留删除文字的行为。选中条目在进度条以透明度 0.3 的黑色条带预览范围，不自动改写公共 ID／Range 或执行编辑。左侧 ↗ 定位列可直接选中该记录并跳到首帧；Start、End 分别跳到草稿的前后边界，后续可继续拖动主进度条对照检查。

### 5.7.2 恢复范围与发送端点

Use range 将草稿恢复到公共 ID、Range 及相应 All 开关，并解除 Filter 的精确记录编辑作用域。Send 下拉框默认 **Focused outputs**，使用主窗口最后聚焦的操作输入组，与 Store 的 Focused inputs 对应；也可明确选择接收工具。接收位置少于暂存分区时，先询问要填入哪一部分，取消不改动输入；不会将多部分合并成同一个 ID 列表。

| 目标 | 填入内容与后续操作 |
| --- | --- |
| Range | 恢复公共 ID、Range 及 All 开关 |
| Interpolate / Swap | 填入已有端点；普通范围提供起止帧及可确定的身份，缺少的几何须补全 |
| Trajectory | 选中单一已有目标并填入编辑区间，再选择轨迹操作与预览 |
| Delete | 恢复公共身份及范围并切至 Box，核对后点击 Delete |
| Merge ID | 恢复公共范围并切至 ID；两部分分别填 Target／Source；单部分仍按首个自动 ID 和其余 ID 拆分 |
| Change position | 恢复公共身份及范围并切至 Box，清空旧位置输入，重新指定所需位置 |
| Change class | 恢复公共身份及范围并切至 Box，再选择所需类别 |
| Change ID | 恢复公共身份及范围并切至 ID，再核对新 ID 及整条／范围操作 |
| Choose range | 恢复公共身份及范围并切至 Box，再点击 Select 开始画布范围选择 |
| Tracking / Match binding / Notes | 回填对应操作输入，不执行追踪、绑定或保存 |

Merge Target／Source 可在目标页继续修改；本功能不推断人工轨迹的自动 ID。Interpolate、Swap、Trajectory 使用单一端点区间，多区间草稿发送时取最外侧两端，宜将不连续的独立编辑区间分别暂存。

恢复与 Send 均不执行删除、插值、交换或曲线应用。仍须在目标工具检查几何及身份，再执行操作。目标已不存在不阻止回填草稿；实际执行时按目标工具的必要条件校验。画面引用不能协调时，重新指定草稿；程序不猜测另一条相近轨迹，也不自动建立新身份。

视频索引完成后，暂存端点按画面身份协调帧号；All frames 草稿按完成后的有效总帧数更新。多条草稿保持各自目标与范围，不自动展开为所有 ID × 所有区间的批量操作。

**实例：比较两处可疑段。** 为 ID 7 的 100–140 帧 Store range，命名为“起飞段”；再为 ID 12 的 800–850 帧保存“交叉段”。查阅时仅选择草稿并用 Start／End 定位；需要删除第一段时明确 Use range，核对 ID 7 和范围，再执行 Delete。第二段不会被一起删除。

## 5.8 后处理预览时的编辑保存

在 Raw cache 或后处理预览中，需要先点击框确定来源，再使用这些输入。编辑 Raw 写入 Raw cache；编辑后处理框只修改结果副本，不自动修改 Raw cache 或原审阅标注。需回写时使用 Postprocess settings 的 Apply to Raw，随后手动 Reprocess range；保留结果使用 Save preview。取消参数窗口不撤销框编辑，撤销使用 Undo／Redo。详见[预览编辑与范围重算](04_Detection后处理测试操作说明.md#451-编辑-raw-与结果)。

## 5.9 验收与保存

依次核对身份唯一性、作用范围、位置尺寸、两端交接及来源标记。用 History 撤销已提交的不正确操作；完成后 Save as。插值、合并、改号和交换的目的不同，应按错误类型选择，不以最终曲线是否平滑作为唯一验收标准。
